# Stress Free Staffing & Events

A division of [Stress Free Group LLC](https://www.StressFreeGroup.com) — full-service experiential marketing, staffing, and event production.

## Tech Stack

- React 19 + Vite
- CSS Modules
- Deployed on Vercel

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Connected to Vercel via GitHub. Push to `main` triggers production deploy.
